# 聚云（Juyun）

聚云是一个只给自己使用的 iOS 多网盘聚合器。v1.11 统一接入 115、百度网盘、夸克网盘、阿里云盘、天翼云盘和迅雷云盘，覆盖文件预览、上传下载和常用云端文件管理，不再只是视频播放器。

> 数据路径：网盘服务商 ⇄ iPhone。项目不包含中转服务器，不会把文件或凭证上传到开发者自有服务。

## 已实现

- 任意文件点击预览：视频与音频直连播放，图片原图缩放，PDF、Office、iWork、文本、压缩包和其他系统支持格式使用 iOS Quick Look。
- 目录浏览、下拉刷新、当前文件夹筛选、名称/日期/大小排序、文件详情和多选。
- 从 iOS“文件”选择器批量上传；显示校验、上传、合并进度。
- 新建文件夹、重命名、移动、复制、删除，以及批量下载到本机。
- 下载任务暂停、继续、取消；暂停任务可在 App 重启后继续，完成后可再次预览或通过 iOS 分享面板导出。
- 115、百度和阿里支持服务端全盘搜索；其他网盘仍可筛选当前文件夹。

## v1.11 修复与优化

- App 重启恢复已完成下载时，会把本机文件的实际字节数与日志中的已知总大小再次精确核对；被截断、替换或损坏的文件会删除并改为失败，不再继续显示为可预览的完成任务。
- 下载元数据临时日志与主日志改为按实际修改时间选择最新有效快照；临时日志只有确实更新时才优先，同一时间或时间信息不可用时以主日志为准，避免旧临时记录回滚新状态。
- 115、百度、夸克、天翼和迅雷在完成整文件哈希、分片哈希、证明码或二次验证后，会在向网盘创建上传/秒传任务前再次核对源文件大小与修改时间，避免校验结果与随后上传的内容不一致。
- 天翼目录分页会结合服务端总数判断是否仍有下一页；即使某一页不足 60 项，只要总数尚未取完就继续请求，同时保留空页、重复页和 1,000 页上限保护。
- 19 组核心回归测试增加完成文件大小、日志新旧排序和短页分页边界，并继续通过 Expo SDK 57 严格类型检查。

## v1.10 修复与优化

- 每次下载或继续下载都拥有独立运行代次；快速“暂停 → 继续”时，上一阶段迟到的空结果或错误不会再把新阶段改成失败，也不会释放仍在使用的原生任务。
- 下载目标在原生任务真正结束前保持引用计数占用。取消或移除后立刻重新下载同名文件，也不会因旧任务迟到回调而删除、覆盖新文件。
- Quick Look 临时预览增加单文件 512 MB 硬上限；已知超限会直接提示改用下载，未知大小在传输进度超限时会主动取消并清理半成品。
- 后台 Token、Drive ID 回写前会与 Keychain 最新凭证快照比较；用户刚保存的新 Cookie、Token 或空间配置不会被旧请求覆盖。
- HTTP Header 的单值 64 KB 与整组 256 KB 上限按 UTF-8 实际字节计算，多字节内容不能再绕过原生网络栈保护。
- 上传源必须是无远程主机、查询参数或片段的本机文件 URI；复制出的临时分片会核对存在性和精确字节数，并在上传前再次复核源文件。
- 分享或预览操作尚未返回时，“移除记录”和“删除文件”会同步禁用；设置页版本号改为读取 App 配置，避免发布版本显示不一致。
- 19 组核心回归测试已扩展覆盖下载运行代次、路径引用计数、UTF-8 Header 总量和陈旧凭证快照，并继续通过 Expo SDK 57 类型检查。

## v1.9 修复与优化

- Keychain 账号 ID 现在严格符合 SecureStore 键名规则，并明确限制最多保存 500 个账号，避免极端情况下出现“本次保存成功、重启后账号不可见”的孤立凭证。
- 下载地址会拒绝原始控制字符和内嵌用户名密码；断点文件 URI 必须是完整、无远程主机、无查询参数的本机地址，整份暂停状态还增加 220 KB 字节上限。
- HTTP Header 会拒绝大小写不同的重复名称及非法控制字符；服务商响应按 UTF-8 实际字节限制 20 MB，不再让多字节文本绕过容量检查。
- 取消正在暂停的任务时会可靠释放旧原生下载句柄；本机目标占用判断使用规范化路径，避免不同 URI 写法指向同一文件。
- 上传每个分片前都会重新确认源文件大小与修改时间，降低用户在选择文件后替换内容造成校验值和上传内容不一致的风险。
- 百度网盘移动或复制时会同时识别目标目录 ID 与路径；选回原目录会正确提示无需操作，不再向服务商提交注定失败的同目录请求。
- 文件名在任何合法长度预算下都不会超过 UTF-8 上限；原生 HMAC、RSA 与本机路径入口增加编码、密钥长度和空字符校验。
- 扩展后的 19 组无账号核心回归测试覆盖以上边界，并继续通过 Expo SDK 57 类型检查、iOS 预构建和生产 Bundle 验证。

## v1.8 修复与优化

- 未知文件总大小的下载不再从第一个数据块开始就显示 100%；恢复出的异常进度也会按实际字节重新校正。
- 文档预览先下载到每次请求独有的临时文件，完整校验后再原子发布到缓存；返回、重试或旧回调不会再删除新任务的缓存文件。
- 暂停信息在保存、启动恢复和继续下载三个阶段都必须指向同一个聚云 `Downloads` 文件，损坏或串任务的断点数据会被拒绝。
- 传输历史最多保留 500 条并优先保留排队、下载中和暂停任务；待完成任务最多 100 条，升级时旧暂停任务不会被大量完成历史挤掉。
- 下载日志增加 10 MB 上限；孤立断点状态改为受控并发清理，单条清理失败会保留索引供下次重试。
- 空白根目录 ID 会回退到对应网盘默认根目录；账号保存后界面使用 Keychain 中实际持久化的时间戳与凭证副本。
- 传输页会阻止暂停、继续、分享和删除文件的重复点击；原生文件接口拒绝带主机或查询参数的伪本机 URI，以及源目标相同的复制。
- 严格类型检查与 19 条无账号核心回归测试覆盖缓存竞态、断点路径、历史迁移、未知大小进度和既有关键路径。

## Windows 11 开发与 TestFlight

本项目使用 Expo SDK 57 和 EAS Build。你不需要自己拥有 Mac：JavaScript/TypeScript 开发在 Windows 完成，iOS 原生编译和签名由 EAS 的 macOS 云构建机完成。

准备：

1. 开通付费 Apple Developer Program，并确保 Apple ID 已启用双重认证。
2. 安装 Node.js 22.13 或更高版本、Git，以及 iPhone 上的 TestFlight。
3. 注册 Expo 账号；Apple 与 Expo 的密码都只在各自官方登录流程中输入。

在 Windows PowerShell 进入项目目录：

```powershell
npm install
npm run typecheck
npm test
npx eas-cli@latest login
npx eas-cli@latest build --platform ios --profile production --auto-submit
```

首次构建时，EAS 会引导登录 Apple Developer、创建或选择签名证书和 Provisioning Profile。上传完成后，在 App Store Connect 的 TestFlight 页面等待处理，再把自己的 Apple ID 添加为内部测试员。详细流程见 [TESTFLIGHT_WINDOWS.md](./TESTFLIGHT_WINDOWS.md)。

## 本机调试

Expo Go 不包含聚云的 Quick Look、流式哈希和天翼上传加密模块。文件预览、上传、后台下载和 Keychain 最终以 EAS development build 或 TestFlight 真机结果为准。

```powershell
npx eas-cli@latest build --platform ios --profile development
```

开发构建安装到 iPhone 后：

```powershell
npm start
```

手机和电脑应处于可互通网络；若局域网发现失败，可在 Expo CLI 中使用 tunnel 模式。

## 六家网盘的凭证准备

聚云不会让你直接输入网盘密码。请只使用自己的账号，并遵守对应网盘的服务条款和开放平台规则。

- **115**：从 115 开放平台授权流程获得 Access Token 与 Refresh Token；根目录 ID 默认为 `0`。
- **百度网盘**：在百度开放平台创建个人应用并完成 OAuth 授权。只填 Access Token 也可使用；同时填写 Refresh Token、Client ID、Client Secret 后，App 可在过期时续期。
- **夸克网盘**：使用夸克 Open API 发放的 App ID、Sign Key、Access Token。当前本地版不通过第三方刷新服务续期，过期后在设置中替换 Token。
- **阿里云盘**：在阿里云盘开放平台创建应用并完成授权。空间类型默认 `resource`；如你的文件位于默认或备份空间，改为 `default` 或 `backup`。
- **天翼云盘**：在电脑浏览器登录 `cloud.189.cn` 后，从自己的请求中复制完整 Cookie。Cookie 失效时重新获取；不要提供账号密码。
- **迅雷云盘**：粘贴自己账号的 OAuth Access Token。风控要求验证时还需对应的 Captcha Token 与 Device ID；只有填写 Client Secret 和 Refresh Token 时才会尝试自动续期。

部分服务商会调整私有或半开放接口。遇到 401、登录失效、验证码或风控错误，先更新凭证；若接口结构变化，再更新 `src/providers/` 下对应适配器。

## 项目结构

```text

  components/       通用 UI
  config/           六家网盘配置与主题
  context/          账号、下载任务与状态
  providers/        六个适配器
  native/           iOS Quick Look、哈希与上传加密桥接
  screens/          首页、连接、浏览、预览、传输、设置

```

## 当前边界

- 手动暂停后的下载可在 App 被彻底终止并重新打开后继续；正在下载但尚未暂停的任务若未由 iOS 后台完成，则需要重新发起。上传需保持 App 运行，当前不支持中途取消或断点续传。
- 115 与迅雷当前使用单请求上传，单文件上限 5 GB；其他网盘采用各自分片接口。会员限速、服务端秒传、单文件限制和并发限制仍由服务商决定。
- 云端分享链接、收藏、保险箱、回收站恢复、离线下载等并非六家都具有统一开放接口，本版未伪装成跨平台通用按钮；本机文件仍可通过 iOS 分享面板发送到其他 App。
- 未在发布包中放入任何真实凭证，因此无法自动完成六家真实账号的端到端测试。首次 TestFlight 安装后，应按下方真机清单逐家验收。
